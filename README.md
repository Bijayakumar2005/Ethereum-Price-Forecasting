# 📈 Ethereum Price Forecasting Using Machine Learning

A data science project focused on **time series analysis and forecasting of Ethereum prices** using machine learning techniques. This project demonstrates data preprocessing, visualization, model building, and evaluation for financial forecasting.

---

## 🔍 Project Overview

Cryptocurrency markets are highly volatile. This project aims to:
- Analyze historical Ethereum price data
- Visualize trends and patterns
- Apply machine learning models for price forecasting
- Evaluate model performance

---
